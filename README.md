# .github

Welcome to the Health Navigator repositories!

This repository serves as an index and documentation hub for the Health Navigator suite of
applications. It provides links and brief descriptions for backend APIs, user interfaces,
and Azure Functions related to patient data processing, synchronisation, notifications,
prediction, and proactive healthcare management. The repo helps users navigate and understand
the purpose of each component in the Health Navigator ecosystem.

## HN Engage

### [API](https://github.com/health-navigator/hn-engage-api)

This repository provides the backend API for the Health Navigator Engage platform. It is built with Node.js (NestJS)
and PostgreSQL, and exposes RESTful endpoints for managing patient data, contracts, addresses, medical facilities,
and related entities. 

The API supports database migrations, backups, audit logging, file uploads, and integrates with Azure services
for cloud storage and configuration. It includes development tools, environment-based configuration, and automated
testing to support healthcare data workflows and proactive patient management.

### [UI](https://github.com/health-navigator/hn-engage-ui)

This repository contains the frontend application for the Health Navigator Engage platform. 
Built with React, TypeScript, and Vite, it integrates with backend APIs, supports authentication,
localisation, and includes tools for development, testing, and deployment.

## HN Nexus

### [Data Input Function](https://github.com/health-navigator/hn-nexus-data-func-apps)

This repository implements an Azure Durable Functions for the Health Navigator Nexus platform, focused on
patient data processing and synchronization. It handles automated workflows for ingesting,
validating, and upserting patient prediction, opt-out, and re-identification data from Azure Blob
Storage into the Engage application and it's own PostgreSQL database.

These functions are triggered by files being updated (in any way) in specified Azure Blob Storage Containers.

### [Data Sync Function](https://github.com/health-navigator/hn-nexus-data-sync-func-apps)

This repository implements Azure Functions for synchronizing patient data between the Nexus, Engage,
and Proactive healthcare platforms. It automates workflows for ingesting, validating, and transferring
patient records, assessment booking information and related metadata between Engage and Proactive.

This function is triggered by the Data Input function running as it will sync the incoming data into the
applications, it also runs on a timer to sync between both web applications.

### [Notifications Function](https://github.com/health-navigator/hn-nexus-data-notifications-func-apps)

This repository implements Azure Functions to send notifications to a Slack Channel, currently the `#transfer-alerts`
channel, to notify people when Nexus has done something.

This function is driven by messages added to the Azure EventHub generated by the other Nexus functions.
